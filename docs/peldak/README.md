# Fiktív állásfoglalásminták

A dokumentumok kizárólag kitalált cégeket, személyeket, számadatokat és forrásmegnevezéseket tartalmaznak. A bemutató nem igazol jogforrás-ellenőrzést vagy valós ügyben alkalmazható minősítést; a C-110/13 hivatkozás kutatási tételként szerepel.

- [KKV Word](KKV_allasfoglalas_minta.docx) · [KKV PDF](KKV_allasfoglalas_minta.pdf)
- [Tao Word](Tao_allasfoglalas_minta.docx) · [Tao PDF](Tao_allasfoglalas_minta.pdf)

A minták a megküldött Word tipográfiájához és logikai felépítéséhez igazított formát mutatják. Az első példában a kétéves minősítés, a személyi kapcsolódás és piaci értékelés; a másodikban kapcsolt, nem kapcsolt és nyitott cégpár is szerepel. A céghálók a mentett elrendezés alapján készülnek.

Újragenerálás: `.venv/bin/python scripts/generate_opinion_samples.py` (PDF-hez LibreOffice szükséges). Ez a script a helyi ügyadatbázist nem olvassa és nem módosítja.
